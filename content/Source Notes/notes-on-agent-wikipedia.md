## What it says

The page 'Agent - Wikipedia' is a disambiguation page for the term 'agent', spanning espionage, law, arts, biology, and computing. For the computing sense, it defines agent architecture as a blueprint for software agents and control systems, an agent-based model as a computational model simulating individuals' actions and interactions, agentic AI as autonomous artificial intelligence that can make decisions and act on them on its own, an intelligent agent as an autonomous, goal-directed entity that observes and acts upon an environment, a software agent as a piece of software that acts for a user or another program, and a user agent as software that acts on behalf of a user. It gives no claims about how such agents are built or evaluated; it only distinguishes the computing senses from other legal, biological, and historical uses.
